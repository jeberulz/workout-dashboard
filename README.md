# Workout Dashboard

A 6-day Push–Pull–Legs workout dashboard built from Mr Wad's Instagram reel
([@stylup_africa._](https://www.instagram.com/reel/DfcQJcRMF-b/)) — "Best program
to Build Muscle & Lose Fat".

- Mon Push · Tue Pull · Wed Legs · Thu Push · Fri Pull · Sat Legs · Sun rest
- 36 exercises in the reel's exact order
- Tick off sets, track progress, rest timer

The reel names the exercises but gives no sets, reps, or weights — the
dashboard's set/rep ranges are starter suggestions, clearly labelled as such.

Open `index.html` in a browser, or visit the live site on Vercel.
